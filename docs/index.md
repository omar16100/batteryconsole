# Documentation index

Conventions for this project:

- Dated documents: `DDMMYYYY_topic.md` (e.g. `27092026_readme_ci_plan.md`)
- Evergreen documents: `topic.md` (e.g. `c4model.md`)
- Every new document must be registered in the table below.

## Categories and required sections

| Category | Required sections |
|---|---|
| Architecture | Context, Containers, Components, Data flow, Decisions |
| Plan | Goal, Status, Milestones, Decisions, Deviations |
| Reference | Purpose, Usage, Examples |
